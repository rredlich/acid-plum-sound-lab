    USB message format (for the firmware)

    "Send to device" sends one SysEx message per bank over Web MIDI to the port named "Acid Plum" (firmware V1.0.7 or later, built with Tools → USB Stack → Adafruit TinyUSB). The device replies F0 7D 41 50 10 01 cmd bank status detail F7 (status 0 = accepted). "Restore factory banks on device" sends F0 7D 41 50 02 01 01 F7. Envelopes travel as attack / decay / sustain / release and the device converts them to its 4 points: t0 = A, t1 = A + D, t2 = t1 + 1, t3 = R, levels 1, S, S, 0.
